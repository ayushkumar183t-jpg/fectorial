Task1: Factorial of a Number Program
This Python program computes the factorial of a number by employing a function and a loop. The program accepts a number input from the user and sends it to a function called factorial(). Within the function, a loop multiplies every integer from 1 through the specified number to compute the factorial. In the end, the program shows the calculated factorial on the screen. 

Task 2: Mathematical Operations with the Math Module
This Python program carries out various mathematical operations by leveraging the built-in math module. The program accepts a number input from the user and computes its square root, natural logarithm ( log base e), and sine. The computed results are then shown on the screen.
